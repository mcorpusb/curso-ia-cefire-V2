# NotebookLM para docentes
{: .fs-8 }

Convierte tus documentos en una base de conocimiento conversacional.
{: .fs-5 .fw-300 }

> **Página en construcción · V2**
> NotebookLM (Google) permite cargar hasta 50 fuentes (PDFs, documentos, URLs, vídeos de YouTube) y obtener respuestas que priorizan y fundamentan sus respuestas en esas fuentes. Herramienta clave del Bloque 2. Recuerda: una cita no garantiza que la interpretación sea correcta; consulta siempre la fuente original cuando la información sea importante.
