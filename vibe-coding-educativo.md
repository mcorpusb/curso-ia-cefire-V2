## 1. ¿Qué es el vibe coding?

El **vibe coding** consiste en crear aplicaciones conversando con una IA. En lugar de programar desde cero, el docente describe qué quiere construir, prueba el resultado, detecta errores y mejora la herramienta mediante nuevas instrucciones.

No es magia, ni programación en el sentido tradicional. Es una nueva manera de construir herramientas digitales usando el **lenguaje natural** como interfaz principal.

<div class="callout callout--idea" role="note" aria-label="Definición de vibe coding">
<div class="callout__titulo">💡 En palabras de Juanjo de Haro</div>
"Es hacer programas a través de la IA. Le dices lo que quieres y lo hace."
<br><br>
La clave está en la conversación con la IA, refinando la idea paso a paso hasta obtener una aplicación funcional que puedes integrar en tus clases.
</div>

### ¿Qué cambia con el vibe coding?

| Antes | Con vibe coding |
|:------|:----------------|
| Necesitabas saber programar | Necesitas saber describir lo que quieres |
| El desarrollo tardaba semanas | Un primer prototipo puede estar listo en horas |
| Hacías falta equipos técnicos | Un docente puede hacerlo solo |
| Las herramientas eran genéricas | Las puedes adaptar a tu grupo, tema y objetivo |
| Publicar costaba dinero o recursos | GitHub Pages permite publicarlas gratis |

### Tres ideas importantes antes de empezar

- **No sustituye el criterio pedagógico.** La IA acelera la parte técnica, pero el valor educativo sigue estando en el diseño docente.
- **El resultado requiere revisión.** Las aplicaciones generadas deben comprobarse antes de usarlas con el alumnado.
- **La idea didáctica viene primero.** Sin un objetivo pedagógico claro, la herramienta no será útil aunque esté bien programada.

<div class="callout callout--reflexion" role="note" aria-label="Reflexión sobre el diseño pedagógico">
<div class="callout__titulo">🔍 Una buena aplicación educativa nace de una buena necesidad didáctica.</div>
Antes de abrir la IA, pregúntate: ¿qué problema real del aula quiero resolver? ¿Qué haría el alumnado que ahora no puede hacer sin esta herramienta?
</div>

## 2. ¿Qué relación tiene con los agentes de IA?

Los agentes de IA y el vibe coding son dos enfoques distintos pero complementarios para usar la inteligencia artificial en educación.

Un **agente de IA** actúa como un asistente especializado: guía, organiza, adapta y responde dentro de una conversación. Un recurso de **vibe coding** es una aplicación interactiva que el alumnado usa directamente: un juego, un simulador, un cuestionario dinámico.

| Agente de IA | Vibe Coding |
|:-------------|:------------|
| Ayuda al docente a organizar tareas | Ayuda a construir herramientas interactivas |
| Adapta contenidos según el contexto | Genera prototipos funcionales desde cero |
| Evalúa o guía en una conversación | Crea simuladores, juegos y aplicaciones educativas |
| Funciona como asistente inteligente | Funciona como un creador de recursos digitales |
| El producto es texto o una propuesta | El producto es una aplicación usable en el aula |
| Lo usa el docente para preparar | Lo usa el alumnado directamente |

<div class="callout callout--idea" role="note" aria-label="Complementariedad entre agentes y vibe coding">
<div class="callout__titulo">💡 Cómo se complementan</div>
Si un agente ayuda al docente a <strong>pensar y organizar</strong> una tarea, el vibe coding ayuda a <strong>convertir esa idea en una herramienta funcional</strong>. Ambos usan la IA, pero con propósitos diferentes y complementarios.
</div>

## 3. El proceso paso a paso

El vibe coding no es caótico: sigue una secuencia lógica que cualquier docente puede aprender.

<div class="vibe-timeline" role="list" aria-label="Proceso de creación de una aplicación educativa mediante vibe coding">

  <div class="vibe-timeline__paso" role="listitem">
    <span class="vibe-timeline__num">1.</span>
    🎯 <strong>Necesidad docente</strong> — Identificas un problema real en el aula que una herramienta digital podría resolver.
  </div>

  <div class="vibe-timeline__paso" role="listitem">
    <span class="vibe-timeline__num">2.</span>
    💡 <strong>Idea de aplicación</strong> — Defines qué tipo de herramienta necesitas: simulador, juego, cuestionario, mapa interactivo...
  </div>

  <div class="vibe-timeline__paso" role="listitem">
    <span class="vibe-timeline__num">3.</span>
    ✍️ <strong>Prompt inicial</strong> — Escribes la descripción de la aplicación para la IA: qué hace, para quién, con qué elementos.
  </div>

  <div class="vibe-timeline__paso" role="listitem">
    <span class="vibe-timeline__num">4.</span>
    🤖 <strong>Prototipo generado por la IA</strong> — La IA genera el código de la primera versión funcional.
  </div>

  <div class="vibe-timeline__paso" role="listitem">
    <span class="vibe-timeline__num">5.</span>
    🔍 <strong>Prueba docente</strong> — Abres la aplicación, la usas y anotas qué funciona y qué no.
  </div>

  <div class="vibe-timeline__paso" role="listitem">
    <span class="vibe-timeline__num">6.</span>
    🛠️ <strong>Corrección y mejoras</strong> — Describes los errores a la IA y pides los cambios necesarios con nuevas instrucciones.
  </div>

  <div class="vibe-timeline__paso" role="listitem">
    <span class="vibe-timeline__num">7.</span>
    🔄 <strong>Nueva versión</strong> — La IA actualiza el código y tú vuelves a probar. El ciclo se repite hasta que la herramienta funciona bien.
  </div>

  <div class="vibe-timeline__paso" role="listitem">
    <span class="vibe-timeline__num">8.</span>
    🏫 <strong>Uso en el aula</strong> — Publicas la aplicación (por ejemplo, en GitHub Pages) y la integras en tu práctica docente.
  </div>

  <div class="vibe-timeline__paso" role="listitem">
    <span class="vibe-timeline__num">9.</span>
    🌐 <strong>Compartir con la comunidad</strong> — Publicas tu aplicación en el repositorio de Vibe Coding Educativo para que otros docentes puedan usarla o mejorarla.
  </div>

</div>

<div class="callout callout--practica" role="note" aria-label="Consejo sobre el proceso iterativo">
<div class="callout__titulo">✅ El secreto del vibe coding es la iteración</div>
No esperes que el primer resultado sea perfecto. La clave es describir bien lo que quieres, probar, detectar errores y mejorar. Cada vuelta del ciclo acerca la herramienta a lo que necesitas.
</div>

## 4. ¿Qué es la comunidad Vibe Coding Educativo?

[Vibe Coding Educativo](https://vibe-coding-educativo.github.io) es una **comunidad abierta, colaborativa y centrada en docentes** que quieren crear aplicaciones educativas interactivas usando inteligencia artificial.

No es un producto comercial ni una plataforma de pago. Es un espacio de conocimiento compartido donde docentes de todos los niveles aprenden, publican y mejoran herramientas educativas juntos.

## 8. Actividad práctica: diseña tu primera app educativa con IA

{: .fs-5 .fw-300 }

Esta actividad guía al profesorado en el proceso de crear una primera aplicación educativa sencilla usando vibe coding. No necesitas tener ningún conocimiento técnico previo.

### Pasos

1. **Detecta una necesidad real del aula.**  
   ¿Qué actividad repites muchas veces? ¿Qué recurso digital mejoraría tu práctica? ¿Qué hace tu alumnado que podría hacerse de forma más interactiva?

2. **Define el objetivo didáctico.**  
   ¿Qué debe aprender o practicar el alumnado con esta herramienta? Escríbelo en una sola frase clara.

3. **Describe la idea con palabras sencillas.**  
   Imagina que le explicas a un compañero qué quieres construir: qué hace la aplicación, a quién va dirigida, qué elementos tiene.

4. **Escribe un prompt inicial para la IA.**  
   Usa la plantilla de abajo como punto de partida. Cuanto más concreto seas, mejor será el resultado.

5. **Genera una primera versión con la IA.**  
   Puedes usar ChatGPT, Claude, Gemini u otro modelo de lenguaje con capacidad de generar código HTML.

6. **Prueba la herramienta en tu navegador.**  
   Guarda el código como un archivo `.html` y ábrelo. Comprueba que funciona como esperabas.

7. **Detecta qué falla o qué mejorar.**  
   Anota los errores con precisión: "el botón no responde", "el texto es demasiado pequeño", "falta retroalimentación al alumno".

8. **Mejora el prompt con las correcciones.**  
   Describe a la IA exactamente qué cambiar. Sé específico: "Cuando el alumno acierta, muestra un mensaje de felicitación en verde".

9. **Publica o comparte tu herramienta.**  
   Puedes publicarla en GitHub Pages (gratuito) o compartirla directamente con el grupo de Telegram de la comunidad para recibir opiniones.

### Plantilla de prompt inicial

<div class="callout callout--idea" role="note" aria-label="Plantilla de prompt para crear una aplicación educativa con vibe coding">
<div class="callout__titulo">📋 Copia y adapta este prompt</div>
<div class="prompt-bloque">Quiero crear una aplicación educativa sencilla para [etapa educativa] sobre [tema o contenido].

El objetivo es que el alumnado [describe la acción de aprendizaje, por ejemplo: practique, explore, refuerce, evalúe...].

Necesito que incluya [elementos interactivos: preguntas, botones, retroalimentación, animaciones, puntuación...].

La aplicación debe ser:
- Accesible y visual, con textos claros y tamaño de letra adecuado.
- Usable en el navegador sin instalaciones.
- Sin recopilación de datos personales del alumnado.
- Compatible con móvil y tablet.

Genera el código HTML completo en un único archivo y explícame cómo probarlo.</div>
</div>

<div class="callout callout--practica" role="note" aria-label="Consejo sobre el proceso de mejora iterativa">
<div class="callout__titulo">✅ Recuerda: el primer resultado no tiene que ser perfecto</div>
La mejora es parte del proceso. Cada corrección que describes a la IA te enseña a comunicarte mejor con ella y a obtener resultados más precisos. La habilidad del docente en vibe coding no es saber programar: es saber describir con precisión lo que necesita.
</div>

## 9. Seguridad y privacidad

Crear aplicaciones con IA implica asumir ciertas responsabilidades. Antes de publicar cualquier herramienta para uso en el aula, revisa siempre los siguientes puntos.

<div class="callout callout--seguridad" role="alert" aria-label="Advertencias de seguridad y privacidad para el vibe coding educativo">
<div class="callout__titulo">🔐 Antes de usar cualquier aplicación de vibe coding en el aula</div>

<strong>No hagas esto:</strong>
<ul>
<li>No introduzcas nombres, apellidos ni datos personales del alumnado en la IA para generar la aplicación.</li>
<li>No subas informes psicopedagógicos, expedientes ni documentos internos del centro.</li>
<li>No publiques aplicaciones que recopilen datos personales del alumnado sin las medidas legales adecuadas.</li>
</ul>

<strong>Haz esto siempre:</strong>
<ul>
<li>Revisa la aplicación completa antes de usarla con el alumnado: textos, botones, retroalimentación y comportamiento general.</li>
<li>Valida el contenido generado por la IA: puede contener errores conceptuales o información incorrecta.</li>
<li>Comprueba que la aplicación no solicita ni almacena datos del usuario.</li>
<li>Evita cualquier recopilación innecesaria de información, incluso nombre o correo electrónico.</li>
<li>Mantén la supervisión docente durante el uso en el aula, especialmente con alumnado menor de edad.</li>
<li>Si la aplicación se publica en internet, comprueba que cumple con la normativa de protección de datos aplicable (RGPD, LOPDGDD).</li>
</ul>
</div>

<div class="callout callout--alerta" role="alert" aria-label="Regla de oro de privacidad en vibe coding">
<div class="callout__titulo">⚠️ Regla de oro</div>
Si la aplicación va a ser usada con alumnado menor de 14 años, asegúrate de que no solicita ningún tipo de dato personal, ni siquiera el nombre. Utiliza sistemas de identificación anónimos (número de alumno, color, animal...) si necesitas distinguir al alumnado.
</div>
