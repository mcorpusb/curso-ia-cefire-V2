# Laboratori de prompts educatius
{: .fs-7 }

Tria la teua etapa i un repte pròxim a la teua pràctica. No és una col·lecció de respostes per a copiar: és un espai per a **demanar, comparar, iterar, verificar i decidir**.
{: .fs-5 .fw-300 }

{% include prompt-lab-privacy.html %}

## Un mètode comú

Cada repte dura **15–20 minuts de pràctica docent** i recorre la mateixa seqüència:

**Petició inicial → prompt pedagògic → comparació → iteració → reflexió → decisió docent**

El prompt pedagògic concreta cinc elements: **Context + Alumnat + Objectiu + Restriccions + Format**. Canvia almenys una condició per a ajustar-lo a la teua realitat, sense introduir dades personals.

## Abans de començar

- Obri dues converses noves amb la mateixa ferramenta per a facilitar la comparació.
- Conserva les dues respostes i anota quina informació ha produït cada millora.
- Comprova dades, fonts, càlculs, codi, llenguatge i accessibilitat: més detall no garantix més qualitat.
- Tria **un repte**. Explorar-ne altres és voluntari i estes pràctiques no afigen nous lliuraments ni qualificacions.
