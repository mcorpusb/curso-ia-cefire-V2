DIAPOSITIVA 1: INTRODUCCIÓN Y MISTERIO Plantilla: Dark Futuristic / Game Screen

Elementos visuales: Fondo oscuro con cuadrícula neón. Icono de candado o servidor en alerta roja. Reloj de cuenta atrás.
Texto Clave: "SISTEMA CERO: INTRUSIÓN EN SERVIDOR SMR. Tenéis 20 minutos para analizar los vectores de ataque de Phishing y restaurar las credenciales."

DIAPOSITIVA 2: PRUEBA 1 - REMITENTES FALSOS Plantilla: Email Client Interface

Elementos visuales: Captura o diseño simulado de cliente de correo (Outlook/Gmail retro). Muestra cabeceras con typosquatting como soporte@micros0ft-security.com vs soporte@microsoft.com.
Pregunta: Identificar qué cabecera es ilegítima basándose en el dominio y campo Reply-To.

DIAPOSITIVA 3: PRUEBA 2 - INSPECCIÓN DE ENLACES Plantilla: Web Browser / Inspection Tools

Elementos visuales: Cuadro simulando inspección al pasar el ratón (Hover) sobre un hipervínculo. Muestra URL aparente https://banco.com/login vs URL real destino http://185.220.101.5/login.php.
Pregunta: ¿Qué indicador confirma el fraude? (IP directa sin HTTPS, falta de SSL, discrepancia).

DIAPOSITIVA 4: PRUEBA 3 - PROTOCOLOS Y SEGURIDAD Plantilla: Control Panel / Config

Elementos visuales: Opciones de seguridad de red SMR: Registros DNS SPF/DKIM, 2FA (TOTP vs SMS), Anti-Phishing Gateway.
Pregunta: Configurar la combinación óptima para mitigar ataques futuros.

DIAPOSITIVA 5: PANTALLA DE ÉXITO Y CERTIFICADO Plantilla: Victory / Achievement Badge

Elementos visuales: Insignia de "Ciber-Defensor SMR", código QR con feedback del profesor y espacio para el nombre del equipo.
