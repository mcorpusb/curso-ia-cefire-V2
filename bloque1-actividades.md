# Laboratorio de prompts educativos
{: .fs-7 }

Elige tu etapa y un reto cercano a tu práctica. No es una colección de respuestas para copiar: es un espacio para **pedir, comparar, iterar, verificar y decidir**.
{: .fs-5 .fw-300 }

{% include language-switcher.html %}
{% include prompt-lab-privacy.html %}

## Un método común

Cada reto dura **15–20 minutos de práctica docente** y recorre la misma secuencia:

**Petición inicial → prompt pedagógico → comparación → iteración → reflexión → decisión docente**

El prompt pedagógico concreta cinco elementos: **Contexto + Alumnado + Objetivo + Restricciones + Formato**. Cambia al menos una condición para ajustarlo a tu realidad, sin introducir datos personales.

## Antes de empezar

- Abre dos conversaciones nuevas con la misma herramienta para facilitar la comparación.
- Conserva las dos respuestas y anota qué información produjo cada mejora.
- Comprueba datos, fuentes, cálculos, código, lenguaje y accesibilidad: más detalle no garantiza más calidad.
- Elige **un reto**. Explorar otros es voluntario y estas prácticas no añaden nuevas entregas ni calificaciones.
